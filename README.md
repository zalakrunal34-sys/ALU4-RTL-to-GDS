# 4-Bit ALU RTL-to-GDS Project

## Overview
A 4-bit Arithmetic Logic Unit (ALU) designed using Verilog and processed through the OpenROAD RTL-to-GDS flow.

## Operations
- Addition
- Subtraction
- Bitwise AND
- Bitwise OR
- Bitwise XOR
- Bitwise NOT

## Tools
- Verilog HDL
- OpenROAD
- Nangate45 platform

## Project Files
- alu4.v: Verilog RTL source
- config.mk: OpenROAD configuration
- constraint.sdc: Timing constraints
- 6_final.gds: Final physical layout
- 6_final.odb: Final OpenROAD database
